# Studybloom - My Study Space

A simple and welcoming student organizer designed to help students keep track of their tasks and stay organized.

About the Project

Studybloom is a to-do list website I created to make managing school tasks easier. It provides a simple space where students can list their tasks, track their progress, and keep their workload organized.

# Features

Add Task — Quickly add tasks to your to-do list.
Mark as Completed — Check off tasks once they're finished.
Edit Tasks — Make changes to existing tasks.
Delete Tasks — Remove tasks you no longer need.
Empty-State Illustration — Displays an illustration when there are no tasks on the list.

## Built With
- HTML
- CSS
- JavaScript

# How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

# Why I Built It

I wanted to create something useful for students like me. Keeping track of schoolwork can sometimes feel overwhelming, so I wanted Studybloom to be a simple starting point for organizing tasks and building better study habits.
